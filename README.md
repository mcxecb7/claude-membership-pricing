## Max：100 和 200 美元两档，只有月付

Max 在 Pro 之上给两档用量：5 倍对应每月 100 美元，20 倍对应每月 200 美元。除用量外还有三项 Pro 没有的待遇：所有任务更高的输出上限、新功能的早期访问、高峰时段的优先接入。

两个容易忽略的点：

- Max 没有年付。官方只提供月付订阅，所以 Pro 那种“折合 17 美元”的折扣在 Max 上不存在，两档就是明码的 100 和 200。

## 付费之前先搞懂：用量限制怎么算

Claude 不按消息条数计费，而是给一个用量池，两道限制同时生效：一个是 5 小时滚动窗口，所有档位都有，每 5 小时重置一次；另一个是每周额度，付费档适用，在账户固定的每周时间点重置。

整个账户共享同一个池子。网页、桌面端、手机和 Claude Code 用的是同一份额度，下午跑了一场长代码会话，晚上聊天的余量就会明显缩水。对话越长、模型越大，额度烧得越快——在 Opus 上长聊一下午，和用 Haiku 问十个短问题，完全是两个消耗量级。

撞到限额时有三个选择：等重置、升级套餐，或者付费档开启 usage credits 按标准 API 费率继续用。额度是预充值，可以设每月上限，单日上限 2000 美元。

额度本身也在变宽松：随最近一次旗舰模型更新，官方上调了 Pro、Max、Team 等订阅档的 5 小时限额，并给订阅用户发了一个可保存、随时能用的一次性“额度重置”，可以把 5 小时或每周额度补满一次。

## 免费版、Pro、Max 怎么选

三句话版本：偶尔用用，免费版够了；每天干活，上 Pro；每天高强度干活还老撞限额，才轮到 Max。

展开说。免费版包含联网搜索、跨对话记忆、文件创建和代码执行、扩展思考，能用 Sonnet 和 Haiku，回答问题、翻译、总结几段文字这类轻量需求完全够用。缺点是额度有限、没有 Claude Code、用不了 Opus 和 Fable。

Pro 适合的信号很具体：每天写作或写代码超过半小时、需要用 Claude Code 处理真实项目、经常要传大文档进去分析。这类用法下，年付 200 美元的成本很快能被省下的时间覆盖。

Max 的判断标准更简单——你是不是经常在下午就把 5 小时窗口的额度用完。如果是，而且一周出现好几次，5 倍档就值；连 5 倍都不够，再考虑 20 倍。反过来，一个月只撞一两次限额的话，留在 Pro 更划算。
